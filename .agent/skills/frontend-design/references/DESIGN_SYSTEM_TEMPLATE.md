## ♿ Accessibility Constraints

- **Minimum contrast ratio:** 4.5:1 for body text, 3:1 for large text (WCAG AA)
- **Focus rings:** All interactive elements MUST have a visible `:focus-visible` outline
- **Touch targets:** Minimum 44×44px for all clickable elements (mobile)
- **Motion:** Respect `prefers-reduced-motion` — disable non-essential animations
- **Alt text:** All `<img>` elements must have descriptive `alt` attributes
