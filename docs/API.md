## Key Endpoint Payloads

### POST `/api/calculate`
```json
{
  "variables": [
    { "ID - REF": "MOENDA_TON", "TIPO": "INPUT", "EQUAÇÕES E VALORES": "1500" },
    { "ID - REF": "CALDO_EST", "TIPO": "OUTPUT", "EQUAÇÕES E VALORES": "MOENDA_TON * 0.95" }
  ],
  "tolerance": 0.0001
}
```
